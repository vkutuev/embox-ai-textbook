= Сборка руководства

Руководство собирается из AsciiDoc в PDF с помощью `asciidoctor-pdf`.

== Сборка через Docker (рекомендуется)

[source,shell]
----
docker run --rm -v "$(pwd)":/documents/ \
  asciidoctor/docker-asciidoctor asciidoctor-pdf Course.adoc
----

== Сборка локально

[source,shell]
----
gem install asciidoctor-pdf   # если ещё не установлен
asciidoctor-pdf Course.adoc
----

Результат — `Course.pdf`.
