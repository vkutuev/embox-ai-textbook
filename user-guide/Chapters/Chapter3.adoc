== Установка и настройка OpenCode

Агент работает в инструменте **OpenCode** (v2). Установите его и настройте
модель.

=== Установка

Инструкции по установке — на официальном сайте:

https://opencode.ai[opencode.ai]

OpenCode поддерживает Linux, macOS и Windows (через WSL2).

=== Первый запуск

Запустите OpenCode в терминале:

[source,shell]
----
opencode
----

=== Выбор модели

Агент использует модель текущей сессии, поэтому до начала работы выберите
модель (провайдера), через которую OpenCode обращается к ИИ.
