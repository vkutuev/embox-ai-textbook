== Запуск агента-наставника

=== Откройте проект

Запустите OpenCode в папке с материалами (той, которую вы скачали или
клонировали):

[source,shell]
----
cd embox-ai-textbook
opencode
----

=== Выберите агента

В OpenCode выберите агента *k1921vg1t-mentor* (переключатель агентов в
интерфейсе).

// image::opencode-agent.png[Выбор агента k1921vg1t-mentor]

=== Начните диалог

Напишите любое сообщение — агент ответит и начнёт онбординг (см. следующую
главу).
