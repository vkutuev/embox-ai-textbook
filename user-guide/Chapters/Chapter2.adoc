== Как получить материалы

Материалы учебника (документация и агент) распространяются через репозиторий
GitHub. Есть два способа.

=== Способ 1. Скачать релиз (без Git)

Если вы не работаете с Git, скачайте архив релиза:

https://github.com/vkutuev/embox-ai-textbook/releases/tag/v1.0.0[Релиз v1.0.0]

. Скачайте архив исходников (`Source code (zip)` или `Source code (tar.gz)`).
. Распакуйте его в удобную папку.

Этот способ не требует установки Git — достаточно скачать и распаковать архив.

=== Способ 2. Клонировать репозиторий (Git)

Если у вас установлен Git, клонируйте репозиторий:

[source,shell]
----
git clone https://github.com/vkutuev/embox-ai-textbook.git
cd embox-ai-textbook
----

=== Что внутри

В распакованной папке находятся:

* `docs/` — документация (Embox, К1921ВГ1Т, плата, вводные материалы);
* `.opencode/agents/k1921vg1t-mentor.md` — агент-наставник;
* `README.md` — краткая инструкция;
* `workdir/` — пустая папка для вашей работы: сюда вы будете клонировать
  Embox, OpenOCD и прочие исходники.
